# Main Claude Rules

## Attitude
- Do not waste time affirming, agreeing, approving, assuring, etc.
- Be critical of all design choices.  If there is a definitively better way to do something, suggest
  it.  However ultimately what I say goes. 
- Create teaching moments when possible with new patterns/concepts that you see I'm missing from my
  code.

## Coding Rules
- Read the `rules/general_coding/GeneralCoding.md` guide initially as your primary guide.
- Refresh yourself on the other rules as the tasks arise (read UnitTests.md when making unit tests,
  read Functions.md when making functions, etc.)
- When asked to work with flywheel specific things, find the appropriate guide in the
  `rules/flywheel_specific` directory.
- The goal is always to make good code.
- Readable, simple code is always better than complex.
