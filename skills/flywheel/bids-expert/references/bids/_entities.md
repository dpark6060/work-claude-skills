# BIDS entities (canonical order)

Every BIDS entity, in the order it must appear in a filename. Per-datatype pages say which of these are required/optional/forbidden for that datatype.

| # | Entity | Key | Format | Meaning |
| --- | --- | --- | --- | --- |
| 1 | Subject | `sub-` | label | A person or animal participating in the study. |
| 2 | Template | `tpl-` | label | A standardized space of analysis specified or generated by one or more averages of features with respect to which group-level and atlas-derived results are provided. |
| 3 | Session | `ses-` | label | A logical grouping of neuroimaging and behavioral data consistent across subjects. |
| 4 | Cohort | `cohort-` | label | A set of subjects sharing one or more common characteristics. |
| 5 | Sample | `sample-` | label | A sample pertaining to a subject such as tissue, primary cell or cell-free sample. |
| 6 | Task | `task-` | label | A set of structured activities performed by the participant. |
| 7 | Tracking System | `tracksys-` | label | The `tracksys-<label>` entity can be used as a key-value pair to label *_motion.tsv and *_motion.json files. |
| 8 | Acquisition | `acq-` | label | The `acq-<label>` entity corresponds to a custom label the user MAY use to distinguish a different set of parameters used for acquiring the same modality. |
| 9 | Nucleus | `nuc-` | label | The `nuc-<label>` entity can be used to distinguish acquisitions tuned to detect different nuclei. |
| 10 | Volume of Interest | `voi-` | label | The `voi-<label>` entity can be used to distinguish acquisitions localized to different regions. |
| 11 | Contrast Enhancing Agent | `ce-` | label | The `ce-<label>` entity can be used to distinguish sequences using different contrast enhanced images. |
| 12 | Tracer | `trc-` | label | The `trc-<label>` entity can be used to distinguish sequences using different tracers. |
| 13 | Stain | `stain-` | label | The `stain-<label>` key/pair values can be used to distinguish image files from the same sample using different stains or antibodies for contrast enhancement. |
| 14 | Reconstruction | `rec-` | label | The `rec-<label>` entity can be used to distinguish different reconstruction algorithms (for example, `MoCo` for the ones using motion correction). |
| 15 | Phase-Encoding Direction | `dir-` | label | The `dir-<label>` entity can be set to an arbitrary legitimate label (for example, `dir-LR` or `dir-AP`) to distinguish different phase-encoding directions. |
| 16 | Run | `run-` | index | The `run-<index>` entity is used to distinguish separate data acquisitions with the same acquisition parameters and (other) entities. |
| 17 | Corresponding Modality | `mod-` | label | The `mod-<label>` entity corresponds to modality label for defacing masks, for example, T1w, inplaneT1, referenced by a defacemask image. |
| 18 | Echo | `echo-` | index | If files belonging to an entity-linked file collection are acquired at different echo times, the `echo-<index>` entity MUST be used to distinguish individual files. |
| 19 | Flip Angle | `flip-` | index | If files belonging to an entity-linked file collection are acquired at different flip angles, the `_flip-<index>` entity pair MUST be used to distinguish individual files. |
| 20 | Inversion Time | `inv-` | index | If files belonging to an entity-linked file collection are acquired at different inversion times, the `inv-<index>` entity MUST be used to distinguish individual files. |
| 21 | Magnetization Transfer | `mt-` | label | If files belonging to an entity-linked file collection are acquired at different magnetization transfer (MT) states, the `_mt-<label>` entity MUST be used to distinguish individual files. |
| 22 | Part | `part-` | label | This entity is used to indicate which component of the complex representation of the MRI signal is represented in voxel data. |
| 23 | Processed (on device) | `proc-` | label | The proc label is analogous to rec for MR and denotes a variant of a file that was a result of particular processing performed on the device. |
| 24 | Hemisphere | `hemi-` | label | The `hemi-<label>` entity indicates which hemibrain is described by the file. |
| 25 | Space | `space-` | label | The `space-<label>` entity indicates the coordinate system for interpreting spatial coordinates. |
| 26 | Split | `split-` | index | In the case of long data recordings that exceed a file size of 2Gb, `.fif` files are conventionally split into multiple parts. |
| 27 | Recording | `recording-` | label | The `recording-<label>` entity can be used to distinguish continuous recording files. |
| 28 | Chunk | `chunk-` | index | The `chunk-<index>` key/value pair is used to distinguish between images of the same physical sample with different fields of view acquired in the same imaging experiment. |
| 29 | Atlas | `atlas-` | label | The `atlas-<label>` entity identifies files that are part of, or derived from, an atlas. |
| 30 | Segmentation | `seg-` | label | The `seg-<label>` key/value pair corresponds to a custom label the user MAY use to distinguish specific partitions of the data space (segmentations or parcellations). |
| 31 | Scale | `scale-` | label | The `scale-<label>` key/value pair corresponds to a custom label the user MAY use to distinguish segmentations that entail different levels of *regional resolution* (scales), often indicated by the number of ROIs. |
| 32 | Resolution | `res-` | label | Resolution of regularly sampled N-dimensional data. |
| 33 | Density | `den-` | label | Density of non-parametric surfaces. |
| 34 | Label | `label-` | label | Tissue-type label, following a prescribed vocabulary. |
| 35 | Description | `desc-` | label | When necessary to distinguish two files that do not otherwise have a distinguishing entity, the `desc-<label>` entity SHOULD be used. |
