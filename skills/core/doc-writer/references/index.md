# Doc Type Guides

* [Developer Guide](developer-guide.md) - How to write a client-handoff developer guide that lets the client's developers understand and safely change the code: six required sections, optional sections gated on code complexity, and no internal process or links.
* [Gear README](gear-readme.md) - How to write a Flywheel gear README — start from the SSE skeleton template's README, fill each section from manifest.json and the gear code, and leave the user-owned sections alone.
* [Module / Feature Doc](module-doc.md) - What a module or feature doc includes — purpose, inputs and outputs, key classes and methods, caveats, and an example.
* [README](readme.md) - What a general (non-gear) repo README includes — what it does, prerequisites, quick start, configuration, usage examples, troubleshooting.
