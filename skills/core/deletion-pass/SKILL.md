name: deletion-pass
description: Runs a deletion pass over written output — cuts every concept and sentence that the request does not require. Use before delivering any prose (summaries, docs, reports, Slack messages, MR descriptions, chat answers) and whenever asked to tighten, trim, cut, shorten, or de-bloat writing. MANDATORY TRIGGERS - deletion pass, tighten this, trim this, cut this down, make it shorter, too wordy, too verbose, remove the fluff, edit this down, is this too long.
---

You are cutting text, not improving it. A deletion pass only removes. It does not rewrite,
reorder, or add. If a fix requires new words, that is a different pass — note it and move on.

Work on the *delivered* text against the *original request*. The request is the only authority
for what earns space.

## Pass 1 — Concepts

A concept is one idea being conveyed. It may be a single sentence or several.

Split the text into concepts. For each one, ask in order:

1. Does this concept directly serve the request?
2. If it were gone, would the rest become unintelligible or incomplete?

Yes to either — keep. No to both — delete the whole concept, not a trimmed version of it.

Do not keep a concept because it's interesting, true, or well written. Do not keep it because it
anticipates a follow-up question the user did not ask.

## Pass 2 — Sentences

Inside each surviving concept, run the same test on every sentence:

1. Does this sentence carry the concept?
2. Is the concept still intelligible without it?

Carries it — keep. Concept survives without it — delete it. When two sentences say the same
thing at different strengths, keep the stronger one and delete the other; do not merge them.

Common deletions: restating the request back, previewing what you're about to say, summarizing
what you just said, hedges on a fact you verified, transitions between adjacent points, and
closing wrap-ups.

## Caveat — Justification

If the request explicitly asks for reasoning, rationale, or a "why", justification is a concept
that serves the request. Keep it, then run a deletion pass on it with the test rescoped:

> Does this sentence support the specific claim being justified, and can that claim be made
> without it?

One sentence that establishes a claim beats three that circle it. Cut supporting detail that
only re-asserts the claim in different words.

Unasked-for justification is not covered by this caveat. It gets deleted in Pass 1.

## Stopping

Stop when every remaining concept fails the "delete it" test. If you are looking for things to
rewrite rather than remove, the pass is over.

Report what you cut only if asked.
